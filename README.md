## 目录约定

```
<科目名>/
├── README.md          科目索引：教材、目录结构、内容概览
├── 教材/              教材信息、页码对照、阅读方法、版权声明
├── images/            图表、仿真对照图
└── scripts/           可复现的计算/仿真脚本
```

- 每个科目独立自洽，换科目不影响其他科目。
- `教材/` 目录**只放教材信息与阅读说明，不放受版权保护的教材本体**；版权归原作者及出版方所有。
- `scripts/` 里的脚本应当能独立跑通，产出与 `images/` 中对应的图。
