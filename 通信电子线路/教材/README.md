## ⚠ 扫描版 PDF 的关键技术特征

手里这份 PDF **没有文字层**，这决定了所有读取方式：

| 项目 | 实测值 |
|---|---|
| 页面构成 | 每页 1 张灰度 JPEG |
| 图像尺寸 | 1985 × 3036 px |
| 扫描分辨率 | 240 DPI |
| Creator | DuXiu / SuperStar |
| 文字层 | **无** |

### 由此导致的三个坑

1. **`pdftotext` 几乎无输出** —— 不是文件坏了，是根本没有文字层。只会吐出几个换行符。
2. **按页读取 PDF 只能得到页标题** —— 正文全空。同样是缺文字层，不是工具故障。
3. **PDF 页码 ≠ 书页码** —— 存在 12 页前置偏移（封面、目录、序言等）。

> ### 页码换算
> $$\text{PDF 页} = \text{书页} + 12$$
>
> 反之：**书页 = PDF 页 − 12**

---

## 正确读取流程

```
pdfinfo  →  确认页数与是否含文字层
   ↓（无文字层）
pdfimages -j -f A -l B  input.pdf  outdir\p    抽出页面 JPEG
   ↓
用视觉方式直接读 JPEG 图像
```

工具在 TeXLive 自带工具链中（先 `Get-Command` 探测，不要写死路径）：

```
D:\tools\texlive\2026\bin\windows\pdfinfo.exe
D:\tools\texlive\2026\bin\windows\pdftotext.exe
D:\tools\texlive\2026\bin\windows\pdfimages.exe
```

### 例：读取第 43 ~ 45 页（PDF 第 55 ~ 57 页）

```powershell
pdfimages -j -f 55 -l 57 "教材.pdf" "E:\tmp\scan-txlx\n"
```

会输出 `n-000.jpg`、`n-001.jpg`、`n-002.jpg`…，随后逐张视觉读取。
一次读 1 ~ 4 张，不要一次塞 20 张。

## 判读电路图的注意事项

扫描版电路图的**像素级连通性扫描不能单独作为判读依据**。三条实测教训（来自习题 2.10 的误判与纠正）：

1. **元件标注文字会被误检成导线** —— 题 2.10 中扫描出的「x=847, y=389..487 竖线」，实际是电阻值标注 `10kΩ` 的笔画。二值化后与导线完全一样，纯靠连通性无法区分。判读前必须裁放大图目视确认。
2. **同一条 y 上的多条不同电位引线会被合并** —— 两条平行横线只差 12 px 却分属不同节点。**必须在交叉点检查有无实心结点圆点**，教材图里「交叉不相连」是高频陷阱（题 2.5、题 2.10 都有）。
3. **优先与接入系数定义、官方答案对齐** —— 把「我判成什么」和「官方是什么」的 $p_1,p_2$ 对一遍，比比对数字快得多。$p_1$ 接错会导致 $C$、$A_{u0}$、$Q_L$、通频带全错，而**稳定性结论可能仍然相同**，极易蒙混过关。

详细案例见 [`../习题解答.md`](../习题解答.md) 文末。
