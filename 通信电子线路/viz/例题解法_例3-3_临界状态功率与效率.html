例 3-3　临界工作状态下由饱和临界线斜率与导通角求功率与效率　教材 书页 64–65（PDF 76–77）

题干：某高频谐振功率放大器如图 3-2 所示，已知晶体管的饱和临界线斜率 g_cr 为 1S，晶体管导通电压 U_bz = 0.6V，集电极直流电源 V_CC = 20V，基极直流电源 V_BB = −0.5V，输入电压振幅 U_bm = 2.5V，集电极电流脉冲振幅 I_CM = 2A，且放大器工作于临界状态。试求：直流电源 V_CC 提供的功率 P_=、集电极效率 η_c、谐振回路谐振电阻 R_p 和集电极耗散功率 P_c。

图 3-2　高频功率放大器的原理电路（交流等效，按教材图 3-2 重绘；旁路电容 C_b、C_c 从略）
临界状态的含义（教材 3.3 节）：集电极电流脉冲的最大值正好落在饱和临界线上，即 I_CM = g_cr·U_CES，而 U_CES = V_CC − U_cm。所以本例的 U_cm 不是给定的，而是由饱和临界线斜率 g_cr 与电流脉冲振幅 I_CM 反解出来的。

教材位置：题干 书页 64–65（PDF 页 76–77），解答 书页 65（PDF 页 77）。图 3-2 在 书页 54（PDF 页 66）。答案册《通信电子线路要点分析及习题详解》（第 2 版，2009）第 3 章 3.1–3.38 中没有收录本例，本页全部数值由题干独立复算并与教材印刷值比对。

教材解答：不跳步的五步推导

教材位置：教材《通信电子线路（第 3 版，陈启兴）》第 3 章 3.3 节 例 3-3 —— 题干 书页 64–65（PDF 页 76–77），解答 书页 65（PDF 页 77）。答案册（第 2 版）未收录本例。

先想清楚：临界状态给出的是「电流脉冲顶点正好压在饱和临界线上」这一条几何关系，它把未知的 U_cm 锁死；再由基极回路求出通角 θ_c，查表得到分解系数 α₀、α₁，集电极电流的直流与基波分量就都有了。
卡住了先看提示，不看完整答案
  1. 临界：I_CM = g_cr(V_CC − U_cm) → 先反解 U_cm（式 3-21、饱和临界线斜率）。
  2. 通角：cos θ_c = (U_bz − V_BB)/U_bm（式 3-12），注意 V_BB 是负值。
  3. 分解系数：α₀(θ_c)、α₁(θ_c)（式 3-17、3-18），教材查附录 A 的表。
  4. I_C0 = I_CM·α₀，I_c1m = I_CM·α₁（式 3-17、3-18）。
  5. 功率链：P_= = V_CC·I_C0（式 3-22）→ P_o = ½U_cm·I_c1m（式 3-23）→ η_c = P_o/P_=（式 3-25）→ R_p = U_cm²/(2P_o) → P_c = P_= − P_o（式 3-24）。
展开 / 收起完整解法
① 临界状态反解集电极电压振幅 U_cm

放大器工作于临界状态，集电极电流脉冲的顶点正好落在饱和临界线上。饱和临界线的斜率 g_cr = Δi_C/Δu_CE，故 U_CES = I_CM/g_cr；又 U_CES = V_CC − U_cm（式 3-21）。

I_CM = g_cr · U_CES = g_cr (V_CC − U_cm)
U_cm = V_CC − I_CM / g_cr = 20 − 2 / 1 = 18 (V)(3-21)
② 求通角 θ_c 并查分解系数

基极回路给出发射结电压 u_BE(t) = V_BB + U_bm cos(ω_ct)（式 3-20）；令 i_C(t) = 0 得通角（式 3-12）。

cos θ_c = (U_bz − V_BB) / U_bm = (0.6 − (−0.5)) / 2.5 = 1.1 / 2.5 = 0.44(3-12)
查表 θ_c = 63.9°
α₀(63.9°) = 0.232，α₁(63.9°) = 0.410(3-17)(3-18)

V_BB = −0.5 V 是负偏置（丙类），所以分子是 U_bz − V_BB = 0.6 + 0.5，θ_c 比同 U_bm 的正偏置情况更小。

③ 求集电极电流的直流分量与基波分量，再求 P_=

按式 (3-17)(3-18) 把脉冲电流的直流分量与基波分量振幅求出来，再乘电源电压。

I_C0 = I_CM · α₀(63.9°) = 2 × 0.232 = 0.464 (A)(3-17)
I_c1m = I_CM · α₁(63.9°) = 2 × 0.410 = 0.820 (A)(3-18)
P_= = V_CC · I_C0 = 20 × 0.464 = 9.28 (W)(3-22)
④ 求输出功率、效率与谐振电阻

输出功率只由基波分量产生（式 3-23）；效率由式 (3-25) 给出；再由式 (3-23) 反解谐振电阻。

P_o = ½ U_cm I_c1m = ½ × 18 × 0.820 = 7.38 (W)(3-23)
η_c = P_o / P_= = 7.38 / 9.28 × 100% ≈ 79.5%(3-25)
R_p = U_cm² / (2P_o) = 18² / (2 × 7.38) = 324 / 14.76 = 21.95 (Ω)(3-23)
⑤ 求集电极耗散功率 P_c

按能量守恒（式 3-24），直流输入减去输出就是晶体管上耗散的功率。

P_c = P_= − P_o = 9.28 − 7.38 = 1.90 (W)(3-24)
教材答案汇总：P_= = 9.28 W；η_c ≈ 79.5%；R_p = 21.95 Ω；P_c = 1.90 W（连带 P_o = 7.38 W）。
教材存疑并列说明（照教材原样排印，不擅自改教材结论）：
① 分解系数取表值：教材由 cos θ_c = 0.44 查表得 θ_c = 63.9°，并取 α₀(63.9°) = 0.232、α₁(63.9°) = 0.410。用式 (3-17)(3-18) 的连续公式复算：θ_c = arccos(0.44) = 63.891°，α₀ = 0.231 48、α₁ = 0.409 40。教材取表值与精确值差 0.2%–0.15%，在教材末位取舍范围内，教材结论未改；页面下方对撞表同时给出「按教材查表值」与「按精确公式」两条链。
② η_c 的取位：教材印 79.5%。按教材查表值算得 7.38/9.28 = 79.525 9%（≈79.5%）；按精确系数算得 79.585%（≈79.6%），两者都四舍五入到 79.5% / 79.6% 之间的边界，页面并列给出。
