例 3-2　由输出功率与电压振幅求集电极效率、谐振电阻、基波电流振幅与导通角　教材 书页 64（PDF 76）

题干：某谐振高频功率放大器如图 3-2 所示，集电极直流电源 V_CC = 30V，输出功率 P_o = 10W，晶体管集电极电流中的直流分量 I_C0 = 400mA，输出电压振幅 U_cm = 28V。试求：直流电源 V_CC 提供的功率 P_=、集电极效率 η_c、谐振回路谐振电阻 R_p、基波电流振幅 I_c1m 和导通角 θ_c。

图 3-2　高频功率放大器的原理电路（交流等效，按教材图 3-2 重绘；旁路电容 C_b、C_c 与输入/输出耦合变压器从略）

教材位置：题干 书页 64（PDF 页 76），解答 书页 64–65（PDF 页 76–77）。图 3-2 在 书页 54（PDF 页 66）。答案册《通信电子线路要点分析及习题详解》（第 2 版，2009）第 3 章 3.1–3.38 中没有收录本例，因此本页全部数值由题干独立复算并与教材印刷值比对。

教材解答：不跳步的五步推导

教材位置：教材《通信电子线路（第 3 版，陈启兴）》第 3 章 3.3 节 例 3-2 —— 题干 书页 64（PDF 页 76），解答 书页 64–65（PDF 页 76–77）。答案册（第 2 版）未收录本例。

先想清楚：先把「直流」「基波」「回路」三件事分开：直流侧只出现 V_CC 与 I_C0；交流侧只出现 U_cm 与 I_c1m；谐振回路把两者用 R_p 联系起来；θ_c 最后由波形系数 g₁ 反查。
卡住了先看提示，不看完整答案
  1. 直流电源提供的功率：P_= = V_CC · I_C0（式 3-22）。
  2. 效率：η_c = P_o / P_=（式 3-25），注意分子是输出到负载的功率，不是直流输入功率。
  3. 谐振电阻：由 P_o = U_cm²/(2R_p) 反解 R_p（式 3-23）。
  4. 基波电流振幅：由 P_o = ½U_cm I_c1m 反解 I_c1m（式 3-23）。
  5. 导通角：先算电压利用系数 ξ = U_cm/V_CC 与波形系数 g₁ = I_c1m/I_C0，再查附录 A 的表。
展开 / 收起完整解法
① 求直流电源 V_CC 提供的功率 P_=

集电极电源供给的是直流功率，等于电源电压与集电极电流直流分量之积（式 3-22）。

P_= = V_CC · I_C0(3-22)
= 30 V × 400 mA = 30 × 0.4 = 12 (W)
② 求集电极效率 η_c

集电极效率是输出功率与直流电源提供的功率之比（式 3-25）。

η_c = P_o / P_= = 10 / 12 × 100% ≈ 83.3%(3-25)
③ 求谐振回路谐振电阻 R_p

谐振回路只把集电极电流的基波分量变换成回路两端的电压，直流分量与谐波分量都被滤掉，因此输出功率满足式 (3-23)。由它反解 R_p：

P_o = U_cm² / (2R_p) = ½ U_cm I_c1m(3-23)
R_p = U_cm² / (2P_o) = 28² / (2 × 10) = 784 / 20 = 39.2 (Ω)
④ 求基波电流振幅 I_c1m

仍用式 (3-23)，由输出功率与电压振幅求电流振幅。

I_c1m = 2P_o / U_cm = 2 × 10 / 28 = 0.714 286… ≈ 0.72 (A)(3-23)
⑤ 求导通角 θ_c

式 (3-25) 还有另一形式 η_c = ½ξg₁(θ_c)。其中电压利用系数 ξ = U_cm/V_CC，波形系数 g₁(θ_c) = I_c1m/I_C0 = α₁(θ_c)/α₀(θ_c)（式 3-17、3-18 的定义）。先算出 ξ 与 g₁，再查附录 A 的分解系数表得通角。

ξ = U_cm / V_CC = 28 / 30 = 0.933 3
g₁(θ_c) = I_c1m / I_C0 = 0.714 286 / 0.4 = 1.785 7 ≈ 1.79
η_c = ½ ξ g₁(θ_c) = ½ × 0.933 3 × 1.785 7 = 0.833 3 = 83.3%(3-25)
查表 g₁(θ_c) = 1.79 → θ_c ≈ 60°

教材第 (5) 步的写法是 η_c = 0.5 ξ g₁(θ_c) = 0.5 U_CM g₁(θ_c)/V_cc = 0.5 × 28 × g₁(θ_c)/30 = 83.3%，反解 g₁(θ_c) = 1.79 —— 与上面的分步写法完全等价，只是把 ξ 提前并进了式子。

教材答案汇总：P_= = 12 W；η_c ≈ 83.3%；R_p = 39.2 Ω；I_c1m ≈ 0.72 A；θ_c ≈ 60°。
教材存疑并列说明（照教材原样排印，不擅自改教材结论）：
① I_c1m 的取位：教材印「I_c1m = 2P_o/U_cm = 20/28 ≈ 0.72(A)」；20/28 的精确值是 0.714 286… A，严格按两位有效数字四舍五入应为 0.71 A，教材取 0.72。页面按教材印 0.72 A 展示，同时给出精确值 0.714 286 A；两种取法在 1% 以内。
② θ_c 的取表口径：教材由 g₁ = 1.79 查附录 A 表得 θ_c ≈ 60°。用式 (3-17)(3-18) 的连续公式反查 g₁(θ_c) = 1.785 7 对应 θ_c ≈ 61.2°（g₁(60°) = 1.794 3，g₁(61.2°) = 1.785 8）。差异来自表格分辨率，教材结论 θ_c ≈ 60° 保留，页面读数给出连续解 61.2° 并在此说明。
③ 无答案册可对撞：答案册（第 2 版）第 3 章未收录例 3-2，本页数值全部为按题干的独立复算结果，与教材印刷值的偏差列在下方对撞表里。
