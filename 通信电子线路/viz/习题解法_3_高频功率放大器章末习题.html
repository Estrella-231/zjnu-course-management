3.1 习题 3.1 概念题

教材 书页 79（PDF 91）｜答案册 书页 43（PDF 52）
教材原题（照抄）

为什么高频功率放大器一般要工作于乙类或丙类状态？为什么采用谐振回路作负载？为什么负载回路的谐振频率要等于工作频率？

① 为什么工作在乙类或丙类

高频功率放大器的任务是把直流功率尽可能有效地转换成射频功率。甲类放大器的电流波形是完整的正弦，直流分量大、基波分量小，即使理想满功率输出，效率也只有 50%；乙类、丙类只让晶体管在导通角 2θ_c 内导通，静态时几乎不耗直流功率（丙类导通角小于 180°，基极还加负偏置），效率可以提高到 75% 以上。

式 (3-25)：η_c = ½ξg₁(θ_c)，θ_c 越小 g₁ 越大，效率越高；θ_c = π（甲类）时 η_c 最高也只有 50%。

② 为什么用谐振回路作负载

谐振回路（并联 LC）在工作频率上呈现最大的动态电阻，能把集电极电流脉冲的基波分量高效地变换成电压；同时它是一带选频的网络，只让基波（工作频率）通过，把直流分量与各次谐波滤掉，从而实现不失真放大。若用电阻负载，谐波无法滤除，效率与波形质量都会下降。

③ 为什么谐振频率要等于工作频率

只有当负载回路的中心频率等于输入信号的中心频率（工作频率）时，回路对工作频率呈现的阻抗最大（并联谐振时阻抗最大），放大器的电压增益最大、输出功率最大；同时该频率上回路相移为零，容易满足振荡/选频要求。

答案要点（照抄答案册）：① 为了提高效率；② 谐振回路作负载可以提高放大器的电压增益，选取有用信号，抑制无用信号和噪声；③ 负载回路的中心频率等于工作频率（输入信号的中心频率），回路才会对工作频率呈现最大阻抗、电压增益最大。
展开／收起参考答案要点

答案册 书页 43（PDF 52）要点：高频功率放大器一般要工作于乙类或丙类状态是为了提高效率；采用谐振回路作负载可以提高放大器的电压增益，选取有用信号，抑制无用信号和噪声；负载回路的中心频率等于工作频率（输入信号的中心频率），回路才会对工作频率…状态，即阻抗最大，电压增益最大。

3.2 习题 3.2 概念题

教材 书页 79（PDF 91）｜答案册 书页 43（PDF 52）
教材原题（照抄）

为什么低频功率放大器不能工作于丙类状态？而高频功率放大器可以工作于丙类状态？

① 低频功率放大器不能工作于丙类

低频功率放大器的输入信号频率很低，甚至含直流分量。若工作于丙类（导通角小于 180°），电流波形严重失真；采用谐振回路作负载时，回路的电感 L 就要取得很大，电感的损耗与体积随之剧增，回路 Q 值做不高、选频作用差，最后连放大能力都没有。所以低频功放只能在甲类（少数用乙类配变压器）工作。

② 高频功率放大器可以工作于丙类

高频时频率高，谐振回路所需的 L、C 都可以做得很小，损耗小、Q 值高，选频能力强；而且高频率下可以用小尺寸的谐振回路把集电极电流脉冲的基波取出、把谐波滤掉，因此失真不构成问题，丙类的高效率优势得以保留。

答案要点（照抄答案册）：低频功放的输入信号频率低甚至有直流成分，工作于丙类且用谐振回路作负载时输出必然失真；谐振回路的电感…会很大，回路的损耗…很大，以致没有放大能力。高频功放频率高，谐振回路的电感和电容都很小，回路损耗小，可实现不失真放大。

3.3 习题 3.3 概念题

教材 书页 79（PDF 91）｜答案册 书页 43（PDF 52）
教材原题（照抄）

丙类高频功率放大器的动态特性曲线与低频甲类功率放大器的负载线有什么区别？为什么会产生这些区别？动态特性的含义是什么？

① 动态特性的含义

动态特性指在大信号（信号幅度可与静态工作点相当）条件下，集电极电流 i_C 与发射结电压 u_BE、管压降 u_CE 之间的瞬时对应关系，即 i_C = f(u_BE, u_CE)。它是晶体管在小信号特性曲线基础上按实际工作轨迹导出的折线（式 3-26 ~ 式 3-29）。

② 与甲类负载线的区别

甲类低频功放的负载线只是输出特性曲线在放大区内的一段（u_CE 从 V_CC 到某个下限，电流全程连续）；丙类高频功放的动态特性是 AB-BC 折线，横跨截止区、放大区和饱和区：AB 段是放大区内的斜线（斜率 g_d 为负），BC 段落在 u_BE < U_bz 的截止区（i_C = 0），A 点可能越过饱和临界线进入饱和区。

③ 产生区别的根本原因

丙类高频功放的有源器件工作在截止区、放大区甚至饱和区，而甲类低频功放的器件始终只在放大区。

答案要点（照抄答案册）：低频甲类功率放大器的负载线只有在放大区内的一段，而丙类高频功率放大器的动态特性曲线有两段，在截止区、放大区和饱和区都涉及。产生区别的根本原因是丙类高频功率放大器的有源放大器件可能工作在截止区…放大区，而低频甲类功率放大器的有源放大器件只可能工作在放大区。

3.6 习题 3.6 计算题

教材 书页 80（PDF 92）｜答案册 书页 44–45（PDF 53–54）
教材原题（照抄）

谐振功率放大器的集电极电源电压 V_CC、谐振回路两端电压振幅 U_cm 和谐振电阻 R_p 保持不变，当通角 θ_c 由 100° 减少为 60° 时，效率变化了多少？相应的集电极电流脉冲的振幅 I_CM 变化了多少？

① 效率随通角的变化

效率只通过波形系数 g₁(θ_c) 依赖通角（式 3-25），V_CC 与 U_cm 不变即 ξ 不变。

η_c = ½ ξ g₁(θ_c)(3-25)
g₁(100°) ≈ 1.49（精确 1.488 0），g₁(60°) ≈ 1.80（精确 1.793 6）
η_c(100°) ≈ 0.745 U_cm / V_CC
η_c(60°) ≈ 0.90 U_cm / V_CC
η_c(60°) / η_c(100°) ≈ 0.90 / 0.745 ≈ 1.21
② 电流脉冲振幅的变化

由 I_C0 = I_CM·α₀(θ_c)（式 3-17）与 I_c1m = I_CM·α₁(θ_c)（式 3-18）消去 I_CM，再用 U_cm = I_c1m R_p：

I_CM = I_c1m / α₁(θ_c) = U_cm / (R_p g₁(θ_c) α₀(θ_c))
α₀(100°) ≈ 0.350（精确 0.349 3），α₀(60°) ≈ 0.218（精确 0.218 0）
I_CM(100°) = U_cm / (R_p × 1.49 × 0.350) ≈ 1.917 5 U_cm / R_p
I_CM(60°) = U_cm / (R_p × 1.80 × 0.218) ≈ 2.548 4 U_cm / R_p
I_CM(60°) / I_CM(100°) ≈ 2.548 4 / 1.917 5 ≈ 1.33
③ 结论
答案：通角由 100° 减到 60°，效率近似提高 21%（η_c 比值 ≈ 1.21）；集电极电流脉冲振幅 I_CM 增大近 33%（比值 ≈ 1.33）。

3.8 习题 3.8 概念题

教材 书页 80（PDF 92）｜答案册 书页 45（PDF 54）
教材原题（照抄）

高频功率放大器的欠压、临界、过压状态是如何区分的？各有什么特点？当 4 个外界因素，即集电极电源电压 V_CC、基极电源电压 V_BB、谐振回路两端的电压振幅 U_cm 和负载电阻 R_L 只变化其中一个时，放大器的工作状态将如何变化？（教材第 3 版原文如此；第 4 个因素应为「输入电压振幅 U_bm」，见下方教材勘误说明。）

① 三种工作状态的区分

按动态特性直线与饱和临界线的相对位置区分：集电极电流脉冲的最大值全部落在饱和临界线右方（未进入饱和区）→ 欠压；最大值正好落在饱和临界线上 → 临界；最大值穿过饱和临界线进入饱和区 → 过压。

② 各有什么特点

欠压：动态特性完全落在放大区，电流脉冲是标准余弦，输出电压幅度小，效率偏低（≤ 临界）。临界：电流脉冲峰值刚好到达饱和临界线，输出功率与效率都达到该条件下的最大值，丙类功放通常设计在此。过压：电流脉冲顶部被饱和区削平（凹顶脉冲），输出电压幅度大、效率下降，集电极耗散功率增大、晶体管容易过热损坏。

③ 四个单变量变化的影响

判据：动态特性在 u_CE = U_cemin = V_CC − U_cm 处的电流峰值 I_CM，与饱和临界线在该处的电流 g_cr·U_cemin 相比——I_CM 小于 g_cr·U_cemin 时电流全部落在临界线右方（欠压），两者相等时为临界，I_CM 大于 g_cr·U_cemin 时穿入饱和区（过压）。其中 I_CM = g_c(V_BB + U_bm − U_bz) 只由 U_bm 与 V_BB 决定，而 g_cr·U_cemin 随 U_cemin 抬高而增大。于是：

· U_bm 增大 → I_CM 增大 → 由欠压经临界进入过压
· V_BB 增大 → 静态工作点抬高，θ_c 增大（式 3-12），I_CM 增大 → 由欠压经临界进入过压
· V_CC 增大 → U_cemin = V_CC − U_cm 抬高、饱和临界线随之抬高 → 由过压经临界进入欠压
· R_L 增大 → U_cm = I_c1m·R_L（式 3-23）随之增大 → U_cemin 减小，更易穿入饱和 → 由欠压经临界进入过压
答案要点（照抄答案册，第 2 版）：当集电极电流都在临界线的右方时，交流输出电压比较低，称为欠压工作状态；当其集电极电流的最大值穿过了临界线到达左方饱和区时，交流输出电压比较高，称为过压工作状态；当其集电极电流的最大值正好落在临界线上时，称为临界工作状态。对于欠压和临界状态，由于集电极电流为尖顶脉冲，可以用前面所述的分解系数；对于过压状态，由于集电极电流为凹顶脉冲，不能直接用前述的分解系数，但仍然可以分解成傅里叶级数后，用类似的方法计算。随着 R_L 的增大，工作状态由欠压到临界再到过压；随着 V_CC 的增大，工作状态由过压到临界再到欠压；随着 V_BB 的变化，工作状态由欠压到临界再到过压；随着 U_bm 的增大，工作状态由欠压到临界再到过压。
教材勘误并列说明：教材第 3 版书页 80 本题第 4 个因素印的是「谐振回路两端的电压振幅 U_cm」，而答案册（第 2 版）书页 45 印的是「输入电压振幅 U_bm」，答案册的解答文字也按 U_bm 论述（随 U_bm 增大，状态由欠压到临界再到过压）——本页按答案册与校注口径，以 U_bm 为准展开，教材原文已照抄保留在上面的「教材原题」栏，可据以对照。若按教材原印的 U_cm 理解，U_cm 增大时状态同样由欠压经临界进入过压（U_cemin = V_CC − U_cm 减小，更易穿入饱和），差别只在机理：U_cm 直接抬高集电极电压摆幅，U_bm 则先抬高静态工作点、加大 θ_c 与 I_CM。

① 答案册的原因分析（照抄要点）

输入信号的振幅 U_bm 不变，放大器变成了过压状态，集电极的电流是一个凹顶脉冲。由 η_c = P_o/(V_CC I_C0)、V_CC 和 U_cm 不变可知，R_p 必然增大，I_c1m 和 I_C0 减小；由发射结电压的最大值 U_BEmax 不变知道 U_bm 和 V_BB 也不变。引起这种情况的可能性有 3 种：
（1）R_p 增大；（2）g_c 减小，引起动态特性中直线 AB 的斜率绝对值减小；（3）U_bz 增大，引起 Q 点下移。
对于第一种和第二种情况，通角 θ_c 不变；而对于第三种情况，通角 θ_c 减小。

② 本页的定量核对：原来状态的量

由式 (3-25) 与分解系数表：

P_=(原) = P_o / η_c = 3 / 0.60 = 5 (W)(3-22)
g₁(76°) = α₁(76°)/α₀(76°) = 0.458 40 / 0.272 68 = 1.681 12
ξ = U_cm / V_CC = 2η_c / g₁(θ_c) = 2 × 0.60 / 1.681 12 = 0.713 81(3-25)
③ 新状态对波形系数的要求

V_CC 与 U_cm 不变即 ξ 不变，于是新状态的波形系数必须为：

g₁(新) = 2η_c(新) / ξ = 2 × 0.68 / 0.713 81 = 1.905 27（比原来的 1.681 12 提高 13.3%）
④ 通角 θ_c 的两种可能

（i）若原因是 ① R_p 增大 或 ② g_c 减小：u_BEmax、U_bm、V_BB 都不变，由式 (3-12) cos θ_c = (U_bz − V_BB)/U_bM 可知 θ_c 保持 76° 不变。

在仍按余弦脉冲近似、且 I_CM 由基极回路锁定的条件下：

P_o(新) = P_o(原) × α₁(θ_c,新) / α₁(76°) = 3 × 0.279 69 / 0.458 40 ≈ 1.83 (W)(3-23)

教材原题（照抄）

某谐振功率放大器原工作于欠压状态。现在为了提高输出功率，将放大器调整到临界状态。试问：可通过分别改变哪些量来实现？当改变不同的量调到临界状态时，放大器的输出功率是否都一样大？

① 可以改变哪些量

由临界条件 I_CM = g_cr U_cm 与 U_cm = I_c1m R_p = I_CM α₁(θ_c) R_p，可知调整到临界的途径有四类：

· 增大负载电阻 R_p（R_p 增大 → U_cm 增大 → 趋近临界）
· 减小电源电压 V_CC（U_cm 的上限被压低 → 趋近临界）
· 增大输入电压振幅 U_bm（θ_c 与 I_CM 增大 → 趋近临界）
· 增大电源电压 V_BB（θ_c 增大 → I_CM 增大 → 趋近临界）
② 输出功率是否一样大

不一样。由式 (3-23) P_o = ½U_cm I_c1m = ½ I_c1m² R_p = ½ U_cm²/R_p 可以看出：
· 增大 R_p：U_cm 增大、I_c1m 减小，输出功率增大；
· 减小 V_CC：U_cm 减小而 I_c1m 减小得更多，输出功率不变（此时 ξ 变小，效率下降）；
· 增大 U_bm：θ_c 与 I_CM 增大，输出功率增大；
· 增大 V_BB：θ_c 增大，输出功率增大。

答案要点（照抄答案册）：增大负载电阻，输出功率也增大；减小电源电压 V_CC，输出功率不变；增大输入电压振幅 U_bm，输出功率也增大；增大电源电压 V_BB，输出功率也增大。

√(400 / (50 + r₀) − 1) = 100 r₀ / (50 + r₀)

r₀ = 1.337 9 (Ω)

某谐振功率放大器的基极电源电压 V_BB = −0.2V，导通电压 U_bz = 0.6V，晶体管的饱和临界线跨导 g_cr = 0.4S，集电极电源电压 V_CC = 24V，谐振电阻 R_p = 50Ω，输入电压信号 u_b(t) 的振幅 U_bm = 1.6V，输出功率 P_o = 1W。求集电极电流最大值 I_CM、输出电压振幅 U_cm 和集电极效率 η_c，并判断放大器工作于什么状态。在电源、输入信号和晶体管的参数不变的情况下，当谐振电阻 R_p 变为何值时，放大器工作于临界状态？这时，输出功率 P_o、集电极效率 η_c 分别为何值？

cos θ_c = (U_bz − V_BB) / U_bm = (0.6 − (−0.2)) / 1.6 = 0.5 → θ_c = 60°(3-12)

U_cemin = V_CC − U_cm = 24 − 10 = 14 (V) ≫ 饱和临界点电压（约 1 V）

P_o = ½ U_cm I_c1m = ½ × 22.721 × 0.200 0 = 2.272 (W)(3-23)
P_= = V_CC I_C0 = 24 × 0.111 5 = 2.676 (W)(3-22)
η_c = 2.272 / 2.676 = 84.90%(3-25)

3.17 习题 3.17 概念题

教材 书页 81（PDF 93）｜答案册 书页 51（PDF 60）
教材原题（照抄）

晶体管倍频器一般工作为什么状态？简述倍频器的基本工作原理。

① 工作状态

倍频器工作在丙类（有的教材也用乙类）状态：导通角小、效率高，且基极偏置取负值使静态时晶体管截止。

② 基本原理

集电极电流脉冲的波形是非正弦的，含有丰富的谐波；用非线性器件（晶体管）把基波变换成一系列谐波，再用选频网络（并联谐振回路）把所需的那次高次谐波选出来送到负载，于是输出频率是输入频率的整数倍。

③ 倍频器的分类

按工作方式分为倍频、低频倍频、宽频带倍频三类。

答案要点（照抄答案册）：倍频器分为倍频、低频倍频、宽频带倍频三类；工作原理是让集电极电流脉冲通过非线性器件产生谐波，再用选频网络把所需的高次谐波选出。
