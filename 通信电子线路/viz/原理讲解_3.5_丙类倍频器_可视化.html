3.5　丙类倍频器

倍频器的功能是把频率为 fc 的输入信号变换成频率为 n fc 的输出信号（n 为正整数）。 在丙类放大器中，晶体管集电极的脉冲电流中含有丰富的谐波分量，把集电极谐振回路调谐在 n 次谐波上， 输出电压就只有 n 次谐波电压，也就实现了 n 次倍频。本页按教材 3.5 节的顺序，把式 (3-30)～(3-34) 全部拆开重绘， 并把分解系数 αn(θc) 与倍频输出的估算做成可交互的。

1倍频器是什么、为什么需要（三条优点）

在无线电发射机、频率合成器等电子设备中，广泛地应用了倍频器。它的功能是将频率为 fc 的输入信号变换成频率为 n fc 的输出信号（n 为正整数）。采用倍频器的优点有：

(1)能降低电子设备的主振荡器的频率，有利于提高频率稳定度。振荡器频率越高，频率稳定度越低， 一般情况下，主振荡器频率不宜超过 5MHz。因此，当要求输出频率超过 5MHz 的时候，通常采用倍频器。
(2)在通信机的主振荡器工作频段不扩展的条件下，可以利用倍频器扩展发射机输出级的工作波段。
(3)在调频和调相发射机中，倍频器可以用来加大频偏或相移。
倍频器的前后关系：输入信号频率 fc → 倍频器（n 次） → 输出信号频率 n fc。 主振荡器工作在较低的频率上（有利于频率稳定），再由倍频器把频率提高到需要的工作频率； 调频、调相发射机则借倍频把较小的频偏 Δf、相移 Δφ 放大 n 倍，得到 n Δf 的频偏、n Δφ 的相移。

2三类倍频器原理（丙类脉冲选频 / 模拟乘法器 / 参量倍频器）与频率划分

倍频器按其工作原理可分为 3 类：① 利用丙类放大器，从其电流脉冲中选频出谐波分量而获得倍频；② 模拟乘法器实现倍频； ③ 利用 PN 结结电容的非线性变化，得到输入信号的谐波，经选频回路获得倍频，称为参量倍频器。

① 丙类脉冲选频

利用丙类放大器，从其电流脉冲中选频出谐波分量而获得倍频。 晶体管集电极的脉冲电流中含有丰富的谐波分量，把集电极谐振回路调谐在 n 次谐波上即可取得 n 次倍频。

② 模拟乘法器

模拟乘法器实现倍频。利用乘法运算产生输入信号频率的和频、差频分量，取出 n fc 分量即得倍频输出。

③ 参量倍频器

利用 PN 结结电容的非线性变化，得到输入信号的谐波，经选频回路获得倍频，称为参量倍频器。

按工作频率划分：当工作频率为几十兆赫及其以下时，主要采用三极管丙类倍频器； 当工作频率高于 1000MHz 时，主要采用参量倍频器。

在丙类放大器中，晶体管集电极的脉冲电流中含有丰富的谐波分量。如果集电极谐振回路调谐在 n 次谐波上， 则放大器的输出电压只有 n 次谐波电压，也就实现了 n 次倍频。下面简单地定量分析丙类倍频器。

4通角选取与倍频次数限制（式 3-34 θ_c=120°/n）

由于 n 的增加，集电极电流谐波分量的振幅越来越小，倍频器输出的电压振幅、功率和效率也越来越小。 因此，单级丙类倍频器一般只能用于二倍频或三倍频。如果要提高倍频次数，可以将多级倍频器级联。

倍频次数的限制：随着 n 增加，αn 的最大值依次减小（交互 A 中 n = 1…5 的曲线一目了然）， 倍频器输出的电压振幅、功率和效率也随之下降。单级丙类倍频器一般只能用于二倍频或三倍频； 如果要提高倍频次数，可以将多级倍频器级联。

为了提高 n 次丙类倍频器的功率和效率，选取通角时必须满足

θc = 120° / n 式 (3-34)

5要点小结

1倍频器的功能是将频率为 fc 的输入信号变换成频率为 n fc 的输出信号（n 为正整数）。 三条优点：降低主振荡器频率以提高频率稳定度（主振荡器频率不宜超过 5MHz）；不扩展主振荡器工作频段即可扩展发射机输出级工作波段； 在调频、调相发射机中加大频偏或相移。
2倍频器按工作原理分 3 类：丙类放大器从电流脉冲中选频出谐波分量；模拟乘法器；参量倍频器（PN 结结电容的非线性变化）。 几十兆赫及其以下主要用三极管丙类倍频器，高于 1000MHz 主要用参量倍频器。
3丙类倍频器的原理：集电极脉冲电流中含有丰富的谐波分量，谐振回路调谐在 n 次谐波上， 输出电压只有 n 次谐波电压，即实现 n 次倍频。输出信号 uc(t) = Ucm cos(n ωc t)。
4定量结果：Ucm = Icnm Rp = ICM αn(θc) Rp； Pon = 0.5 Ucm Icnm = 0.5 Icnm2 Rp； ηc = [Ucm αn(θc)] / [2 VCC α0(θc)]。
5限制与选取：n 增加则谐波振幅、输出电压振幅、功率和效率都减小，单级一般只用于二倍频或三倍频，更高倍频次数用多级级联； 为提高功率和效率，通角必须取 θc = 120°/n，才能保证 αn(θc) 为最大值。
自检（对照交互 A、B）：把 n 切到 2、θc 拖到 60°，α2 应达到最大值 —；把 n 切到 3、θc 拖到 40°，α3 应达到最大值 —。在交互 B 中固定其余参数，把 n 从 1 加到 3， Icnm、Pon、ηc 都会随之减小。
