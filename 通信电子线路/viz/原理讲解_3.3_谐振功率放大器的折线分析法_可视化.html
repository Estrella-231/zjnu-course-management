3.3　谐振功率放大器的折线分析法

折线分析法就是把晶体管特性曲线理想化成一条或几条射线（折线），再写出理想化曲线的数学解析式， 从而把非线性问题变成可积的解析问题 —— 只要知道解析式中的晶体管参数，就能方便地求出直流分量 IC0 和基波分量的振幅 Ic1m。本页按教材 3.3.1～3.3.6 的顺序，把式 (3-5)～(3-29)、图 3-4～图 3-12 全部拆开重绘，并把分解系数、输出功率与效率、动态特性、负载特性做成可交互的。

1折线化：晶体管特性曲线的理想化（3.3.1）

从集电极余弦脉冲电流 iC(t) 中求出直流分量 IC0 和基波分量的振幅 Ic1m， 是分析和计算丙类谐振高频功率放大器技术指标的关键。解决这个问题的方法有图解法和 解析近似分析法两种。图解法是从晶体管的实际静态特性曲线入手，从图上取得若干个点， 测量出直流分量 IC0 和基波分量的振幅 Ic1m。图解法的准确度比较高，对电子管比较适用； 而晶体管的特性曲线的个体差异很大，一般不能从手册上得到，只能从晶体管特性测试仪上测量出，难以进行概括性的理论分析， 因此，图解法不适用于晶体管。鉴于此，对于晶体管高频功率放大器来说，可以使用解析近似分析法，即折线分析法。

折线分析法的做法：首先是将晶体管的特性曲线理想化，每条曲线都用一条或几条射线来代替， 然后写出理想化曲线的数学解析式。只要知道这些数学解析式中晶体管的参数，就能够方便地求出直流分量 IC0 和基波分量的振幅 Ic1m。这种方法比较简单，易于进行概括性的理论分析，其缺点是计算的准确度比较低，只能进行估算。

晶体管特性曲线的理想化包括输入特性曲线的理想化、正向传输特性曲线的理想化和输出特性曲线的理想化。 在大信号工作情况下，理想化特性曲线的原理认为：在放大区，集电极电流和基极电流不受集电极与发射极之间电压的影响， 而与发射极电压呈线性关系；在饱和区，集电极电流与管压降呈线性关系。

1.1　输入特性曲线的理想化

输入特性的理想化曲线如图 3-4 中的虚线所示。对于晶体管的输入特性曲线来说，当集电极电压大于一定值时， 集电极与发射极之间电压的改变对基极电流的影响不大，可以近似地认为基极电流与集电极和发射极之间的电压无关， 可以用一条折线表示。延长该折线，与横轴的交点的横坐标为 Ubz，它被称为理想化晶体管的 导通电压或截止电压。

iB = 0，　　　　　　　　　　uBE < Ubz
iB = gb(uBE − Ubz)，　uBE ≥ Ubz 式 (3-5)
gb = ΔiB/ΔuBE 式 (3-6)

式中：gb —— 折线的斜率。由此可见，晶体管输入特性曲线的理想化曲线包括两段： 一段对应晶体管截止的情况；另一段对应晶体管导通的情况。

1.2　正向传输特性曲线的理想化

理想化的晶体管的共射电流放大系数 β 被认为是常数，因此正向传输特性曲线的理想化与输入特性曲线的理想化是一致的。

iC = 0，　　　　　　　　　　ube < Ubz
iC = gc(ube − Ubz)，　ube ≥ Ubz 式 (3-7)
gc = ΔiC/Δube = β · ΔiB/Δube = β gb 式 (3-8)

式中：gc —— 晶体管的跨导。由此可见，晶体管正向传输特性曲线的理想化曲线包括两段： 一段对应晶体管截止的情况；另一段对应晶体管导通的情况。

1.3　输出特性曲线的理想化

输出特性曲线的理想化如图 3-5 中的虚线所示。在饱和区，理想化的折线是集电极电流与管压降成正比； 在线性放大区，理想的折线与管压降 uCE(t) 无关，即一簇平行于横轴的折线。

iC = gcr · uCE，　uCE < UCES
iC = β iB，　　　　uCE ≥ UCES 式 (3-9)
gcr = ΔiC/ΔuCE，　uCE < UCES 式 (3-10)

式中：UCES —— 晶体管饱和时的管压降；gcr —— 饱和区集电极电流的斜率。 由此可见，晶体管输出特性曲线的理想化曲线有多条，每条包括两段：一段对应晶体管饱和导通的情况； 另一段对应晶体管工作于放大区的情况。其中，uCE < UCES 时（在饱和区）， 对应的折线叫作临界线。

2集电极余弦电流脉冲的分解（3.3.2）

由图 3-3 可见，晶体管特性曲线理想化之后，集电极电流一般是一个尖顶、周期脉冲信号。 集电极余弦电流脉冲的分解就是把周期性的集电极脉冲电流分解成如式 (3-3) 和式 (3-4) 所示的傅里叶级数形式， 在已知脉冲最大值 ICM 和通角 θc 的条件下，可以求出直流分量 IC0、 基波分量的振幅 Ic1m 和谐波分量的振幅 Icnm，以便计算放大器的技术指标。

2.1　集电极余弦电流脉冲的表达式

设 ub(t) = Ubm cos(ωct)，则 uBE(t) = VBB + ub(t) = VBB + Ubm cos(ωct)。将这个发射结电压代入式 (3-7)（仅考虑晶体管导通时的电流）， 可得晶体管集电极的电流 iC(t) 为

iC(t) = gc[uBE(t) − Ubz] = gc[VBB + Ubm cos(ωct) − Ubz] 式 (3-11)

当 ωt = θc 时，iC(t) = 0，代入式 (3-11) 可得

cos θc = Ubz − VBB/Ubm 式 (3-12)

式 (3-12) 是计算放大器的通角 θc 的公式。把式 (3-12) 代入式 (3-11) 可得

iC(t) = gc Ubm [cos(ωct) − cos θc] 式 (3-13)

当 ωt = 0 时，iC(t) = ICM，代入式 (3-13) 可得

ICM = gc Ubm (1 − cos θc) 式 (3-14)

将式 (3-14) 代入式 (3-13)，就得到集电极余弦电流脉冲 iC(t) 的表达式为

iC(t) = ICM · cos(ωct) − cos θc/1 − cos θc 式 (3-15)

式 (3-15) 是用脉冲最大值 ICM 和通角 θc 来表示集电极电流的瞬时值。 式 (3-12)、式 (3-14) 和式 (3-15) 是后面进行分析和计算常用的表达式。

iC(t) = 0，　　　　　　　　　　　　　　　　　　　　others
iC(t) = ICM · cos(ωct) − cos θc/1 − cos θc， ωct ∈ [2kπ − θc, 2kπ + θc] 式 (3-16)

式中：k —— 整数。

2.2　集电极余弦电流脉冲的分解

集电极余弦电流脉冲的分解，就是把式 (3-16) 表达的周期信号变换成式 (3-4) 的形式。 傅里叶级数的各个分解系数分别为

IC0 = (1/2π) ∫−ππ iC(t) d(ωct) = ICM · sin θc − θc cos θc/π(1 − cos θc) = ICM · α0(θc) 式 (3-17)
Ic1m = (1/π) ∫−ππ iC(t) cos(ωct) d(ωct) = ICM · θc − sin θc cos θc/π(1 − cos θc) = ICM · α1(θc) 式 (3-18)
Icnm = (1/π) ∫−ππ iC(t) cos(n ωct) d(ωct) = ICM · sin(n θc) cos θc − n sin θc cos(n θc)/0.5πn(n2 − 1)(1 − cos θc) = ICM · αn(θc) 式 (3-19)

式中：αi(θc)，i = 0, 1, ⋯, n，分别指直流分量的分解系数、基波分量的分解系数、 n 次谐波分量的分解系数。这些系数都是通角 θc 的函数，根据上面的公式进行计算是比较烦琐的， 通常可以查表，如本书的附录 A 所示。

α0(θc) = sin θc − θc cos θc/π(1 − cos θc)
α1(θc) = θc − sin θc cos θc/π(1 − cos θc)
αn(θc) = sin(n θc) cos θc − n sin θc cos(n θc)/0.5πn(n2 − 1)(1 − cos θc)，n ≥ 2
g1(θc) = α1(θc)/α0(θc) = Ic1m/IC0 分解系数定义
图 3-6 的三条结论（教材原文）：α0(θc) 是单调上升函数。 α1(θc) 在 θc ≈ 120° 时有最大值，最大值为 0.536。 此时，如果最大值 ICM 和负载电阻 RL 为定值，则输出功率 Po = 0.5 Ic1m2 RL 将达到最大值。但是，当通角 θc = 120° 时， 放大器将工作于甲乙类状态，集电极效率则太低。因此，如果要兼顾输出功率和集电极效率，通角 θc 需要另外取值。 通角 θc = 60° 时，α2(θc) 达到最大值。 θc = 40° 时，α3(θc) 达到最大值。

3输出功率与效率（3.3.3）

根据前面阐述的集电极余弦脉冲的分解和晶体管特性曲线的折线分析，可以方便地计算出放大器的输出功率和集电极效率。 在图 3-2 中，设 ub(t) = Ubm cos(ωct)，则发射结两端的电压和管压降分别为

uBE(t) = VBB + Ubm cos(ωct) 式 (3-20)
uCE(t) = VCC − Ucm cos(ωct) 式 (3-21)

集电极脉冲电流 iC(t) 可以分解成式 (3-4) 的形式，其中直流分量 IC0、 基波分量的振幅 Ic1m 和谐波分量的振幅 Icnm 可以由式 (3-17)、式 (3-18) 和式 (3-19) 求出。 因此，直流电源 VCC 提供的直流功率为

P= = VCC · IC0 式 (3-22)

因为负载回路的谐振频率等于基波频率，回路两端的电压主要是集电极脉冲电流的基波分量在回路两端产生的， 而直流分量和其余分量都可以忽略不计。因此，高频放大器的输出功率可以表示为

Po = (1/2) Ucm Ic1m = (1/2) Ic1m2 RL = Ucm2/2 RL 式 (3-23)

根据能量守恒定律，忽略电阻或等效电阻的功率消耗，晶体管集电极耗散功率可以表示为

Pc = P= − Po 式 (3-24)

根据集电极效率的定义，集电极效率可以表示为

ηc = Po/P= = (1/2) × (Ucm Ic1m)/VCC IC0 = (1/2) ξ g1(θc) 式 (3-25)

式中：ξ = Ucm/VCC —— 集电极电压利用系数； g1(θc) = Ic1m/IC0 = α1(θc)/α0(θc) —— 波形系数。波形系数 g1(θc) 随通角 θc 的变化情况如图 3-6 所示， 可以看出，g1(θc) 随着通角 θc 的增大而逐渐下降。

教材结论（1）：在电压利用系数为 1 的理想条件下，对于甲类放大器，θc = π rad， g1(θc) = 1，效率为 ηc = 50%；对于乙类放大器，θc = 0.5π rad， g1(θc) = 1.57，效率为 ηc = 78.5%；对于丙类放大器，θc < 0.5π rad， g1(θc) > 1，效率 ηc > 78.5%，而且通角越小，效率越高。
教材结论（2）：在负载电阻 RL 一定的情况下，θc = 120° 时，输出功率最大， 但效率只有 66%；θc = 1°～15° 时，效率最高，但是输出功率很小。所以，在实际应用中， 为了兼顾输出功率和效率，通常选取 θc = 60°～80°。

4动态特性（3.3.4）

高频谐振功率放大器的工作状态取决于晶体管的参数、负载电阻 RL、集电极电源电压 VCC、 基极电源电压 VBB 和输入信号振幅 Ubm 5 个参数。分析这 5 个参数的变化对高频功率放大器的性能影响， 可以得到高频功率放大器的各种工作状态的优缺点以及正确调试放大器的方法。

对于工作于丙类状态的高频功率放大器，其负载是等效的并联谐振回路，回路的谐振频率等于输入信号的频率， 在其晶体管的型号、电源电压 VBB 和 VCC、输入信号振幅 Ubm、谐振电阻 RL 一定的条件下，集电极电流 iC(t) 与发射结电压 uBE、管压降 uCE 之间的关系， 被称为动态特性，即 iC = f(uBE, uCE)。

uBE(t) = VBB + Ubm · VCC − uCE(t)/Ucm 式 (3-26)
iC(t) = gc[VBB + Ubm · VCC − uCE(t)/Ucm − Ubz]
= −gc (Ubm/Ucm)[uCE(t) − VCC + Ucm cos θc]
= gd [uCE(t) − Uo] 式 (3-27)

式中：Uo = VCC − Ucm cos θc —— 动态特性曲线在横轴 uCE 上的截距； gd = −gc Ubm / Ucm —— 动态特性曲线的斜率（负值）。显然，式 (3-27) 是 iC(t) 与 uCE(t) 之间的直线方程， 反映了当 uBE(t) ≥ Ubz 时，iC(t) 随 uCE(t) 动态变化的对应关系。

4.1　截距法与虚拟电流法

截距法是在已知截距 Uo 和斜率 gd 的条件下，由式 (3-27) 确定的折线， 连同 uBE < Ubz 时 iC = 0 的折线构成总的动态特性曲线，如图 3-7 中的 AB-BC 折线。 其中，A 点的坐标是 (VCC − Ucm, ICM)，B 点的坐标是 (Uo, 0)， C 点的坐标是 (VCC + Ucm, 0)。

虚拟电流法是在截距法的基础上扩展的一种较为简便的分析方法。在图 3-7 中，AB 的延长线与平行于纵轴、 横坐标为 VCC 的直线的交点为 Q(VCC, IQ)。只要已知 AB 折线的斜率、A 点的坐标、 B 点的坐标和 Q 点的坐标这 4 个值中的任意两个，就可以唯一确定 AB 折线；然后连同 C 点，得到完整的动态特性曲线 AB-BC 折线。IQ 是虚拟的电流，实际上它是不存在的，但是可以被求出，即

IQ = gd[uCE(t) − Uo]|u_CE=V_CC = gd(VCC − VCC + Ucm cos θc) = −gc(Ubz − VBB) 式 (3-28)

4.2　三种工作状态

高频谐振功率放大器有 3 种工作状态，即欠压、临界和 过压。当高频谐振功率放大器的集电极电流都在临界线的右方时，交流输出电压比较低， 称为欠压工作状态；当其集电极电流的最大值穿过了临界线，到达左方饱和区时，交流输出电压比较高， 称为过压工作状态；当其集电极电流的最大值正好落在临界线上时，称为临界工作状态。

在图 3-8 中，第一种动态特性曲线是折线 A1B1-B1C1， A1 点处于放大区，对应 Ucm1 最小，集电极电流是尖顶脉冲，这种状态就是欠压状态； 第二种动态特性曲线是折线 A2B2-B2C2， A2 点处于临界线上，对应 Ucm2 中等，集电极电流也是尖顶脉冲，这种状态就是临界状态； 第三种动态特性曲线是折线 A3B3-B3C3， 虽然 A3 点也处于临界线上，但是此时 uBE = VBB + Ubm 已经让晶体管饱和了， 在 B3A3 延长线上的 A′3 点是一个虚拟点，对应 Ucm3 最大， 集电极电流是凹顶脉冲，这种状态就是过压状态。

分解系数的适用范围：对于欠压和临界状态，由于集电极电流为尖顶脉冲，可以用前面所述的分解系数； 对于过压状态，由于集电极电流为凹顶脉冲，不能直接用前述的分解系数，但仍然可以分解成傅里叶级数后， 用类似的方法计算。通过集电极电流脉冲的幅度和形状，就可以判断功率放大器工作在哪种状态。

5负载特性（3.3.5）

高频谐振放大器的负载特性是指在晶体管、VCC、VBB 和 Ubm 一定时，改变回路谐振电阻 RL，高频谐振功率放大器的工作状态、电流、电压、输出功率和效率随 RL 的变化而变化的关系。此时，由式 (3-12)、式 (3-14) 和式 (3-28) 可知，θc、ICM、 uBEmax = VBB + Ubm 和 IQ 是一定的，也就是说，Q 点的坐标也是一定的，而斜率 gd 为

gd = −gc Ubm/Ucm = −gc Ubm/Ic1m RL = −gc Ubm/ICM α1(θc) RL
= −gc Ubm/gc Ubm (1 − cos θc) α1(θc) RL = −1/(1 − cos θc) α1(θc) RL 式 (3-29)

由式 (3-29) 可见，由于 θc 不变，随着谐振电阻 RL 的增大，gd 的绝对值逐渐变小 （斜率 gd 本身是一个负数）。根据图 3-8 和上面的分析，不难发现，随着谐振电阻 RL 的增大， 高频谐振功率放大器的工作状态变化过程是由欠压到临界再到过压，如图 3-9 所示。

欠压和临界状态：集电极电流为尖顶脉冲，由于 θc、ICM 不变，所以 IC0、 Ic1m 都保持不变，P= = VCC IC0 也不变，而 Ucm = Ic1m RL 与 RL 成正比， Po = (1/2) Ic1m2 RL 与 RL 成正比， ηc = Po/P= 与 RL 成正比， Pc = P= − Po 随着谐振电阻 RL 的增大而减小。
过压状态：集电极电流为凹顶脉冲，随着谐振电阻 RL 的增大，ICM 逐渐减小， IC0、Ic1m 相应地减小，Ucm = Ic1m RL 缓慢地增大， P= 和 Po 也减小，ηc 先增加后减小，Pc 也减小。

教材结论

（1）欠压状态：在欠压状态的大部分范围内，输出功率和效率都比较低，损耗也比较大， 而且随着谐振电阻的变化，输出电压的振幅波动比较大。因此，除了特殊情况外，很少采用这种状态。
（2）临界状态：输出功率最大，效率也比较高，常用于发射机的功率输出级，以获得最大输出功率。
（3）过压状态：当谐振电阻变化时，输出电压的振幅变化较小，多用于要求输出电压维持比较平稳的场合， 如发射机的中间级放大器。值得注意的是，在弱过压区，效率最高，而输出功率比较大。

6电源电压和输入信号对工作状态的影响（3.3.6）

6.1　集电极电压 VCC 变化

在晶体管、RL、VBB 和 Ubm 一定时，改变集电极电压 VCC， 由式 (3-12)、式 (3-14)、式 (3-28) 和式 (3-29) 可知，θc、ICM、 uBEmax = VBB + Ubm、IQ 和 gd 是一定的， Q 点在水平方向平移。随着 VCC 的增大，放大器的工作状态 由过压到临界再到欠压，如图 3-10 所示。在欠压和临界状态，集电极电流为尖顶脉冲， 由于 θc、ICM 不变，所以 IC0、Ic1m 保持不变，从而 Ucm = Ic1m RL 不变，Po = 0.5 Ic1m2 RL 不变， 而 P= = VCC IC0 与 VCC 成正比，集电极耗散功率 Pc = P= − Po 随着 VCC 的增大而增大。在过压状态，集电极电流为凹顶脉冲， 随着 VCC 的增大，ICM 逐渐增大，IC0、Ic1m 相应增大， Ucm = Ic1m RL 增大，P= 和 Po 增大，Pc 增大。 由此可知，在过压状态和理想情况下，输出信号的振幅正比于集电极电压，这正是后面将要讨论的 集电极调幅的工作原理。

6.2　基极电压 VBB 变化

在晶体管、RL、VCC 和 Ubm 一定时，改变基极电源电压 VBB， 随着 VBB 的增大，θc、ICM、IQ 和 gd（θc < 120°）增大， Q 点在垂直方向平移，放大器的工作状态由欠压到临界再到过压， 如图 3-11 所示。在这种情况下，参数的变化比较复杂，这里就不讨论了。 由此可知，在欠压状态下，输出信号的振幅受控于基极电压，这正是后面将讨论的基极调幅的工作原理。

6.3　输入信号振幅 Ubm 变化

在晶体管、RL、VBB 和 VCC 一定时，改变输入信号振幅 Ubm， 随着 Ubm 的增大，Q 点不移动，θc、ICM、uBEmax = VBB + Ubm 和 gd 都增大，放大器的工作状态由欠压到临界再到过压， IC0、Ic1m、Ucm、P=、Po 和 Pc 也随之增加，如图 3-12 所示。

图 3-10 横轴方向务必记牢：横轴 VCC 向右为增大，区域标注顺序是 「过压 | 临界 | 欠压」 —— 与图 3-9 的 RL 轴 「欠压 | 临界 | 过压」 正好相反。正文写得很明确： 「随着 VCC 的增大……由过压到临界再到欠压」。VBB 轴与 Ubm 轴则与 RL 轴同向 （欠压 → 临界 → 过压）。

例 3-2

题：某谐振高频功率放大器如图 3-2 所示，集电极直流电源 VCC = 30 V，输出功率 Po = 10 W， 晶体管集电极电流中的直流分量 IC0 = 400 mA，输出电压振幅 Ucm = 28 V。 试求：直流电源 VCC 提供的功率 P=、集电极效率 ηc、谐振回路谐振电阻 Rp、 基波电流振幅 Ic1m 和导通角 θc。

①求直流电源 VCC 提供的功率 P=
P= = VCC IC0 = 30 × 0.4 = 12 (W)
②求集电极效率 ηc
ηc = Po/P= = 10/12 × 100% ≈ 83.3%
③求谐振回路谐振电阻 Rp
Rp = 0.5 Ucm2/Po = 0.5 × 282/10 = 39.2 (Ω)
④求基波电流振幅 Ic1m
Ic1m = 2 Po/Ucm = 20/28 ≈ 0.72 (A)
⑤求导通角 θc。由
ηc = 0.5 ξ g1(θc) = 0.5 Ucm g1(θc)/VCC = 0.5 × 28 × g1(θc)/30 = 83.3%
可得 g1(θc) = 1.79，查表可得 θc ≈ 60°。
易错点：(a) IC0 = 400 mA 要先换成 0.4 A 再代入，否则 P= 差 1000 倍； (b) 求 Rp 用的是 Po = Ucm2/(2Rp) 的反解式 Rp = 0.5 Ucm2/Po，不要漏掉 0.5； (c) Ic1m = 2Po/Ucm 同样来自 Po = 0.5 Ucm Ic1m； (d) 由 g1 反查 θc 用的是 g1 = α1/α0，不是 α1 本身。

8要点小结

折线分析法核心要点

1把晶体管特性曲线用折线（射线段）近似，得到分段线性解析式（式 3-5 ~ 3-10）。
2集电极电流为尖顶余弦脉冲，用 ICM 和 θc 两个参数唯一确定（式 3-12、3-14、3-15）。
3脉冲经傅里叶分解为 IC0、Ic1m、Icnm，对应分解系数 α0、α1、αn（式 3-17 ~ 3-19，图 3-6）。
4动态特性是 iC 对 uCE 的折线（直线段），截距 Uo、斜率 gd（式 3-27）， 虚拟电流 IQ = −gc(Ubz − VBB)（式 3-28）。
5负载 RL、VCC、VBB、Ubm 变化 → 动态折线平移/转动 → 工作状态改变。
