习题 4.2　概念题书页 109 · PDF 121

教材原题（照抄）

题干：反馈型 LC 振荡器从起振到平衡，放大器的工作状态是怎样变化的？它与电路的哪些参数有关？

① 三个阶段：甲类 → 乙类 → 丙类
阶段晶体管状态导通角 θ放大倍数 A环路增益 |AF|
接通电源（起振）信号极小，工作在甲类θ = 2π（360°）最大（ gm·RL 量级）> 1，振幅指数式增长
振幅长大进入非线性区，转为乙类θ = π（180°）下降仍 > 1，继续增长
振幅更大转为丙类θ < π更小仍 > 1，继续增长
平衡（稳定振荡）保持丙类或乙类θ < π降到 A = 1/F= 1，振幅不再变化

关键在于：起振靠的是小信号放大倍数最大（甲类），而稳幅靠的正是放大倍数随振幅下降到 1/F（乙类、丙类）——这两件事由同一个非线性完成，所以「起振容易、稳幅可靠」并不矛盾。

② 用一个可算的模型把「起振 → 平衡」写清楚

把放大器的增益随振幅的压缩写成 A(u) = A0/(1 + k·u²)，则振幅的逐周变化为 un+1 = A(un)·un。平衡点由 A(um) = 1 定出：

本题um = A0 − 1k/　，　A(um) = A01 + k·um²/ = 1

取教学设定值 A0 = 10、k = 1：um = √(10 − 1) = 3；从 u = 0.05 起迭代，振幅单调上升到 3 后不再变化——这就是「起振 → 平衡」的全过程。

另一个佐证：乙类（θ = π）的理想集电极效率上限为 ηC = π/4 = 78.5%，丙类因导通角更小而效率更高；振荡器为了提高效率，理所当然希望工作点停在乙类／丙类而不是甲类。

③ 它与电路的哪些参数有关
类别具体参数起什么作用
有源器件的参数晶体管的 gm、rbe、β、结电容；器件特性曲线的非线性程度决定 A(u) 随振幅下降的快慢，也就是压缩拐点的位置
静态工作参数ICQ、UCEQ、发射极静态电流 IE决定起始工作点落在特性曲线的哪一段，从而决定起振时是甲类还是已进入乙类
选频网络的参数L、C、QL、回路的有载品质因数与损耗电阻 Rp决定反馈系数 F、环路增益大小与平衡点的位置（也决定振荡频率与稳定度）
卡住了先看提示，不看完整答案
  1. 「工作状态」指放大器的导通角：甲类 360°、乙类 180°、丙类 < 180°。
  2. 起振阶段要求 |AF| > 1，此时信号很小 ⇒ 器件在线性区（甲类），A 最大。
  3. 稳幅靠 A 随振幅下降到 1/F，这只能在非线性区（乙类、丙类）实现。
  4. 「与哪些参数有关」分三类答：有源器件参数、静态工作参数、选频网络参数。

三个空分别对应起振状态、平衡状态、平衡时的增益关系。

① 判据：环路总相移必须等于 0 (mod 360°)
本题φ总 = φ晶体管 + φ互感 ≡ 0 (mod 360°)

互感的同名端规则：同名端（同极性端）上的电压同相，异名端上的电压反相。因此 φ互感 只可能是 0°（两个信号端同为同名端，或同为异名端）或 180°（一个信号端是同名端、另一个是异名端）。

于是判据分两种：

  • 共基接法（基极交流接地）：晶体管相移 φA = 0° ⇒ 必须 φ互感 = 0° ⇒ 集电极端与反馈端必须同为同名端（或同为异名端）。
  • 共发射极接法（发射极交流接地、反馈送回基极）：φA = 180° ⇒ 必须 φ互感 = 180° ⇒ 两个信号端必须一为同名端、一为异名端。
② 逐图判断
子图接法互感的两个「信号端」同名端标注φ总
(a)基极经公共节点接地 ⇒ 共基（φA = 0°）副边上端（接集电极）、原边上端（接发射极）两绕组均在上端标同名端0° ✓
(b)基极接地 ⇒ 共基（0°）上绕组上端（接集电极）、下绕组上端（接发射极）两绕组均在上端标同名端0° ✓
(c)基极接地 ⇒ 共基（0°）副边上端（接集电极）、原边上端（接发射极）两绕组均在上端标同名端0° ✓
(d)发射极接地、反馈送回基极 ⇒ 共发射极（180°）下绕组上端（接集电极）、上绕组下端（接基极）两绕组均在上端标同名端（下绕组的上端与上绕组的下端恰为一异名端）360° ≡ 0° ✓

结论：题 4.3 图的四个子图，同名端都标在两个绕组的「上端」——(a)(b)(c) 靠「同为同名端 → 同相」满足共基接法，(d) 靠「下绕组上端与上绕组下端异名 → 反相 180°」满足共发射极接法。

① 三点式振荡电路的相移判据（本题的钥匙）

把图中的三个电抗记作 Xbe（基极—发射极）、Xce（集电极—发射极）、Xbc（基极—集电极）。三点式振荡电路的相位平衡条件可归纳为：

判据①Xbe 与 Xce 必须性质相同（同为感性或同为容性）
判据②Xbc 与它们性质相反
判据③振荡频率由 Xbe + Xce + Xbc = 0 决定

为什么必须是「同性质」？因为晶体管提供 180°（共发射极）或 0°（共基）的相移后，反馈网络必须提供互补的相移；而三点式网络的反馈相移只有在 Xbe、Xce 同性质时才能凑出这个相移。若两者性质不同，反馈网络的相移永远凑不满 360°，环路相位平衡无解 ⇒ 不可能振荡。

子图XbeXceXbc判据①（同性质？）结论类型
(a)感性感性可感可容✓ 同为感性可能振荡电感三点式
(b)容性感性容性✗ 性质不同不可能振荡—
(c)感性容性感性✗ 性质不同不可能振荡—
(d)容性感性感性✗ 性质不同不可能振荡—

只有 (a) 可能振荡，且因 Xbe、Xce 同为感性，属电感三点式（哈特莱型）电路；若两者同为容性则属电容三点式（考必兹型）。

③ 相位平衡条件：X1 + X2 + X3 = 0

对基极节点 b 与集电极节点 c 列小信号节点方程（晶体管发射极交流接地，取 rπ → ∞、ro → ∞），把 vb、vc 消去后得到

③Y1Y2 + Y1Y3 + Y2Y3 + gm·Y3 = 0

③′1X1X2/ + 1X1X3/ + 1X2X3/ = 0　⇔　X1 + X2 + X3 = 0

把式 ② 代入并乘去分母（s = ω²），得关于 s 的二次方程：

③″(C1+C2+C3)s² − [C2(ω2²+ω3²) + C1(ω1²+ω3²) + C3(ω1²+ω2²)]s + [C2ω2²ω3² + C1ω1²ω3² + C3ω1²ω2²] = 0

它的两个正根分落在 ω1、ω2、ω3 划出的三个区间里；只有落在「X1、X2 同性质、X3 与之相反」那个区间的根才是工作点（这正是 4.4 的判据①、②；另一个根虽然也满足式 ③′，但三点式的基本要求不满足，不能作为工作点）。

教材原题（照抄）

题干：为什么晶体振荡器的频率稳定度比 LC 振荡器的高一些？

① 先把「频率稳定度」写成可比的数
①S = Δff0/，　对选频回路：Δff0/ ≈ 12QL/　⇒　QL = 12S/

可见：频率稳定度直接由选频回路的有载品质因数 QL 决定，QL 越大越稳。

② 两条路线的 QL 差了几个数量级
振荡器选频回路典型 QL频率稳定度 S
LC 振荡器（克拉波、西勒）LC 回路10² – 10³ 量级只能达到 10⁻⁴ 量级
石英晶体振荡器石英晶体10⁵ – 10⁷ 量级（可达 10⁸ 以上）高达 10⁻⁴ ～ 10⁻¹¹ 量级

用 ① 式反算：若 S = 10⁻⁴，则 QL = 1/(2×10⁻⁴) = 5×10³ —— 这正是 LC 回路能够做到的极限；而石英晶体的 Q 值比它高 3～5 个数量级，稳定度自然就高 3～5 个数量级。

以 5 MHz 为例直观对比（教学设定值）：LC 振荡器（S = 10⁻⁴）漂移 Δf = 5 MHz × 10⁻⁴ = 500 Hz；晶体振荡器（S = 10⁻⁹）漂移只有 5 mHz，相差 10⁵ 倍。

③ 为什么晶体的 Q 值能那么高
  • 物理原因：石英晶体的谐振频率由晶片的机械尺寸与弹性决定，而不是由电路元件决定。晶片的尺寸受温度、老化、应力影响极小，而 LC 回路的 L、C 受温度与元件离散性影响大得多。
  • 电路原因：晶体本身的等效电路里损耗电阻 rq 极小（Q = ωqLq/rq 很大），所以回路本身「又高 Q 又少受外部负载影响」。
  • 工程后果：石英晶体的谐振频率可以做得很准（标称值误差 10⁻⁵ ～ 10⁻⁶ 量级），因此用它做选频元件，频率稳定度可达 10⁻⁴ ～ 10⁻¹¹ 量级，广泛用于通信与计时基准。

习题 4.12　概念题书页 110 · PDF 122

教材原题（照抄）

题干：为什么振荡器的振荡频率一般并不等于选频回路的谐振频率？其偏离程度与哪些因素有关？

① 振荡频率由「相位平衡条件」定，不由「选频回路的谐振频率」定

选频回路（LC 回路）的谐振频率 fo 是回路自身的阻抗极大点；而振荡频率 fc 要满足整个环路的相位平衡条件：晶体管相移 φY + 反馈网络相移 φF + 回路相移 φL = 0。只有当 φY + φF = 0（放大器与反馈网络正好不引入附加相移）时，fc 才等于 fo。

回路相移与失谐量的关系（并联谐振回路）：

①φL = −arctan(2QL·Δffo/)　⇒　由 φY + φF = −φL 得
(4-31′)Δf = fo2QL/·tan(φY + φF)　≡　fo2QL/·tan φYF
(4-32′)fc = fo + Δf = fotan φYF2QL/

其中 φYF ≡ φY + φF，即放大器与反馈网络的总附加相移。只要 φYF ≠ 0，fc 就不等于 fo。

② 数值验证（用教材同章习题 4.6 的数据）

习题 4.6：fo = 15 MHz，φY = −18°，φF = 3° ⇒ φYF = −15°。

Q_L=60fc = 15 MHz × [1 + tan(−15°)120/] = 15 × (1 − 0.002233) = 14.9665 MHz
Q_L=20fc = 15 MHz × [1 + tan(−15°)40/] = 15 × (1 − 0.006699) = 14.8995 MHz

相对偏差分别为 −0.223% 与 −0.670%：QL 越小（回路损耗越大），同样的附加相移造成的失谐越大。

③ 偏离程度与哪些因素有关
因素符号对相对偏差 Δf/fo 的影响
回路有载品质因数QLQL 越大偏差越小（偏差 ∝ 1/QL）
放大器 + 反馈网络的附加相移φYF|φYF| 越大偏差越大（偏差 ∝ |tan φYF|）
回路固有谐振频率fo相对偏差与 fo 无关，但绝对频差 Δf ∝ fo
上述三者的偏差（温度漂移、元件离散、老化）ΔQL、ΔφYF、Δfo决定频率的长期稳定性：QL 与 fo 的漂移会直接改变 fc

工程结论：增大回路品质因数 QL、减小 |φYF|、提高电路元件的稳定性，都能降低振荡频率的相对偏差。
